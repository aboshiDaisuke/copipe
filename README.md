# Copipe

コピーしたものを全部覚えておいて、あとから選んで貼り付けられる Mac 用のアプリです。
有料のクリップボードアプリ「Paste」と同じ使い心地を目指して作り、日本語の資料づくりや Final Cut Pro での動画編集で使いやすいように機能を足しています。

## どんなアプリか

- **コピーの履歴**: ⌃⌘V で画面の下に、これまでコピーした文字・画像・リンク・ファイルがカードで並びます。選んで return を押すと、いま使っているアプリにそのまま貼り付けます
- **ピンボード**: よく使う文章や素材を、名前と色の付いたグループに取っておけます。⌃⌘1〜9 で直接開けます
- **探す**: そのまま文字を打つだけで絞り込めます。ひらがな・カタカナ、全角・半角を区別せず、画像の中の文字でも見つかります
- **Final Cut Pro の素材もそのまま**: タイムラインからコピーしたクリップやテロップを保存して、あとで貼り戻せます。カードにはクリップ名・テロップの文字・エフェクト・長さが出ます
- **整えて貼り付け**: 改行を消す、英数字を半角にする、などをしてから貼り付けられます。PDF からコピーした文章を資料に入れるときに便利です
- **日付の差し込み**: 定型文に `{今日}` と書いておくと、貼り付けたときにその日の日付になります
- **ペーストスタック**: 続けてコピーしたものを、⌘V のたびにコピーした順に1つずつ貼り付けます
- **Paste からの引っ越し**: Paste の履歴とピンボードをそのまま読み込めます

### Paste にない機能

Final Cut Pro の素材の中身の表示、日本語に強い検索、画像の文字の読み取り、整えて貼り付け、日付の差し込み、コピー元アプリや種類による自動振り分け、.zip での書き出し・読み込み、プレビューの中での編集。

### 動く環境・データの扱い

- macOS 14 以降
- 自動で貼り付けるには「アクセシビリティ」の許可が要ります（なくてもクリップボードに入れるところまでは使えます）
- コピーした中身はこの Mac の中（`~/Library/Application Support/Copipe/`）にだけ保存し、外には送りません。リンクの題名と画像を出すときだけ、そのページを見に行きます（設定で止められます）
- パスワード管理アプリが「機密」と指定したコピーは保存しません。保存しないアプリも設定で選べます

## ビルド・起動

```sh
./build.sh            # build/Copipe.app を作る
./build.sh install    # /Applications にも入れる
open build/Copipe.app
```

## 使い方

| 操作 | キー |
|---|---|
| 履歴を開く / 閉じる | ⌃⌘V（設定で変更可） |
| 選択を移動 | ← → / home・end |
| まとめて選ぶ | ⇧← ⇧→ / ⌘・⇧ を押しながらクリック / ⌘A |
| 貼り付け | ↵ / ダブルクリック / ⌘1〜9 |
| 書式なしで貼り付け | ⇧↵ |
| 整えて貼り付け（改行を消す・英数字を半角/全角に・前後の空白を取る・「」で囲む） | ⌥↵ |
| コピーだけする | ⌘C（⇧⌘C で書式なし） |
| プレビュー | space / ⌘Y |
| 編集（プレビューの中で名前・文字・画像の向きを変える。⌘S で保存、esc で取り消し）・複製・開く | ⌘E・⌘D・⌘O |
| ピンボードに追加 / 外す | ⌘P |
| 削除 | ⌘⌫ |
| クリップボード・ピンボードの切り替え | ⌘← ⌘→ / tab / ⇧tab |
| 検索 | そのまま文字を打つ（右上のボタンで種類・アプリ・日付でも絞り込み） |
| 閉じる | esc |
| ペーストスタックを始める / 終える | ⌃⌘C（設定で変更可） |
| ピンボードを直接開く | ⌃⌘1〜9（左から数えた番号） |

- 検索は、ひらがな・カタカナ、全角・半角、大文字・小文字を区別しない。画像の中の文字（Mac の文字認識で自動で読み取る）や、Final Cut Pro の素材のクリップ名・テロップ・エフェクト名でも探せる
- Final Cut Pro の素材のカードには、中のクリップ名・テロップ・エフェクトと長さが出る
- 文字の中に `{今日}` `{明日}` `{昨日}` `{日付}` `{曜日}` `{時刻}` `{年}` `{月}` `{日}` と書いておくと、貼り付けるときにその日の日付・時刻に置き換わる
- 設定の「自動でピンボードに入れる」で、「このアプリで」「この種類を」コピーしたら決まったピンボードにも入れられる
- 設定の「書き出し・読み込み」で、履歴とピンボードを1つの .zip にできる（バックアップや別の Mac への引っ越し用。読み込むと今のものに足される）
- カードを右クリックすると、貼り付け・コピー・プレビュー・編集・名前変更・複製・開く・アプリで開く・Finder で表示・シェア・ピンボードに追加・削除ができる。まとめて選んだカードには全部に効く
- カードは引っぱって他のアプリに入れられる（文字は書式なし。option を押しながら引っぱると書式付き）。ピンボードの中では引っぱって並べ替えられる
- ピンボードのタブを右クリックすると、名前と色を変えたり、左右に動かしたりできる。タブを引っぱっても並べ替えられる
- `#3498DB` や `rgb(52, 152, 219)` をコピーすると色の見本のカードになる。リンクはページの題名と画像を出す（設定で止められる）
- ペーストスタック: 始めてからコピーしたものを右側の小さい窓にためて、⌘V を押すたびにコピーした順に1つずつ貼り付ける。全部貼り終わると閉じる
- メニュー（メニューバーのアイコンか、履歴の右上の「…」）から、一時停止・新しいテキストアイテム・ペーストスタック・設定を開ける
- 設定: ショートカット、ログイン時に起動、メニューバーに表示、効果音、貼り付け先（アクティブなアプリへ / クリップボードへ）、常に書式なし、保存期間、履歴の消去、機密情報・一時的なコンテンツを無視、リンクプレビュー、保存しないアプリ、Paste からの引っ越し
- 自動で貼り付けるには「システム設定 > プライバシーとセキュリティ > アクセシビリティ」で Copipe を許可してください。許可がない間は、選んだ項目をクリップボードに入れるだけになります（ペーストスタックで ⌘V のたびに次へ進むのにもこの許可が要ります）
- キーチェーンの「Copipe Local Signing」証明書で署名しているので、ビルドし直してもアクセシビリティの許可は外れない（証明書がないと外れることがある。そのときは一覧から Copipe を一度削除して、もう一度追加する）
- 履歴の保存先: `~/Library/Application Support/Copipe/`（最大2000件と保存期間のどちらかで古いものから消える。ピンボードの項目は数に含めず、消えない）
- クリップボードの中身は全形式を丸ごと保存して、貼り付け時にそのまま戻す（書式付きの文字や、Final Cut Pro・Filmora の素材など）。50MB を超えるものは丸ごとは保存しない

## 動作確認用の起動オプション

- `--snapshot <png>`: 起動時のパネルを画像に書き出す
- `--snapshot-preview <ピンボード番号> <png>`: ピンボードを開いて、パネルと大きいプレビューを書き出す（-1 でクリップボード）
- `--snapshot-edit <ピンボード番号> <png>`: 起動して少し待ってから、最初のカードを編集する画面を書き出す
- `--snapshot-settings <png>`: 設定画面を書き出す

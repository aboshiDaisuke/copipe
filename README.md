# Copipe

Paste 風のクリップボード履歴アプリ（macOS 14 以降）。

## ビルド・起動

```sh
./build.sh            # build/Copipe.app を作る
./build.sh install    # /Applications にも入れる
open build/Copipe.app
```

## 使い方

| 操作 | キー |
|---|---|
| 履歴を開く / 閉じる | ⌃⌘V（メニューバーの「ショートカット」で変更可） |
| 選択を移動 | ← → |
| 貼り付け | ↵ / ダブルクリック / ⌘1〜9 |
| 書式なしで貼り付け | ⇧↵ |
| ピン留め | ⌘P |
| 削除 | ⌘⌫ |
| 絞り込み切り替え | tab / ⇧tab |
| 検索 | そのまま文字を打つ |
| 閉じる | esc |

- メニューバーのアイコンから、一時停止・ログイン時に起動・履歴の消去ができます
- 自動で貼り付けるには「システム設定 > プライバシーとセキュリティ > アクセシビリティ」で Copipe を許可してください。許可がない間は、選んだ項目をクリップボードに入れるだけになります
- 自己署名でビルドしているため、ビルドし直すと許可が外れることがあります。そのときは一覧から Copipe を一度削除して、もう一度追加してください
- 履歴の保存先: `~/Library/Application Support/Copipe/`（最大500件。ピン留めした項目は数に含めず、消えません）
- クリップボードの中身は全形式を丸ごと保存して、貼り付け時にそのまま戻す（書式付きの文字や、Final Cut Pro・Filmora の素材など）。50MB を超えるものは丸ごとは保存しない
- パスワード管理アプリが「記録しないで」と指定したコピーは保存しません
